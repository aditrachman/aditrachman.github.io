Menghubungkan file Excel Lokal ke R Markdown

Menghubungkan file untuk data set di r markdwon caranya gampang betul coy cukup dengan satu library saja bisa langsung enjoy nikmatin data set di r markdown biasanya cara ini enak banget buat olah data gitu.

Gunakan library readxl untuk menghubungkan R markdown ke Excel. Jika belum terinstall, jalankan perintah berikut:


> install.package("readxl")

Membaca File Excel Gunakan fungsi read_excel() untuk membaca file Excel:


```{r}
library(readxl)
# Membaca file Excel
file_path <- "path/to/your/file.xlsx" # Ganti dengan path file
data <- read_excel(file_path)
# Menampilkan data
print(data)
```

kalau mau membaca Sheet Tertentu di file Excel yang punya banyak sheet, tinggal tambahkan code ini


```{r}
data_sheet2 <- read_excel(file_path, sheet="Sheet2" )
print(data_sheet2)
```

Kalau mau membaca Rentang Sel Tertentu di spreadsheet kalian tinggal masukin range nya sel nya saja contoh codenya kek gini:


```{r}
data_range <- read_excel(file_path, range="A1:C10" )
print(data_range)
```
